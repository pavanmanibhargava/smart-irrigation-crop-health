# AI-Powered Smart Irrigation and Crop Health Prediction System

A capstone project that combines machine learning with IoT concepts to predict crop health and optimize irrigation scheduling.

## Project Structure

```
smart-irrigation-crop-health/
│
├── data/                # Datasets
│   ├── raw/             # Original, unprocessed data
│   ├── processed/       # Cleaned and transformed data
│   └── external/        # Third-party data sources
│
├── notebooks/           # Jupyter notebooks for exploration and analysis
├── src/                 # Core source code (ML pipelines, utilities)
├── backend/             # Backend API server
├── frontend/            # Frontend web application
├── database/            # Database schemas and migrations
├── models/              # Trained model artifacts
├── tests/               # Unit and integration tests
├── docs/                # Project documentation
│
├── .gitignore
├── README.md
└── requirements.txt
```

## Getting Started

```bash
# Clone the repository
git clone <repo-url>
cd smart-irrigation-crop-health

# Create and activate a virtual environment
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # macOS/Linux

# Install dependencies
pip install -r requirements.txt
```
